# PRD: MioKey（基于 cffk 的发卡站 UI 重做）

## 问题
CFFK 的界面粗糙、交互差（例：手机端后台侧栏点了菜单项不会收起；前台各页面头部不统一、商品页信息层次混乱）。店主希望拥有自己品牌（MioKey）、观感接近其 Shopify 店 amaeru.com（Rawjoy 主题）的店铺。

## 用户
- 顾客：多在手机上，进店 → 找商品 → 选规格 → 填邮箱 → 付款 → 收卡密/查单。
- 店主（管理员）：桌面与手机都会用后台处理订单、商品、卡密、支付配置。

## 目标
1. 前台：统一外壳（公告条、吸顶头部、搜索、手机菜单、页脚）；首页轮播 + 分类筛选 + 商品网格；商品页清晰的“价格—规格—数量—邮箱—支付—提交”流程，手机端底部固定购买栏；登录/注册/找回密码统一框架；暗色模式；中/繁/英。
2. 后台（第二阶段）：侧栏交互（手机点击后收起、折叠、分组）、表格与表单体验参照 MioCore/mail。
3. 品牌：全站无 CFFK 名称、Logo、链接与更新检查。

## 非目标（锁定区域）
支付、数据库结构与迁移、认证流程、API 契约、发卡、定时任务、供应商同步、订单号格式均不改动；支付页面只改外观。

## 用户故事（前台）
- 作为手机顾客，我打开菜单、点“查询订单”后菜单自动关闭，按返回键也能关闭菜单。
- 作为顾客，我能在头部搜索里输入关键词立即看到匹配商品。
- 作为顾客，我在商品页能一眼看到价格和库存，用胶囊按钮切换规格，用 +/- 调数量，滚动时底部购买栏一直可点。
- 作为夜间用户，我能切换暗色模式且设置被记住。

## 成功指标
- Playwright 走查：桌面 1440 与 iPhone 12 下所有前台页面无控制台错误、无横向溢出；交互检查（菜单、搜索、规格、数量、暗色）全部通过。
- 不新增类型错误；lint/tests/build 通过。
